Drag an asset onto another asset — or, in the graph, onto an aggregate or an entity — to make it depend on it. Only the combinations the model allows accept the drop: the two types must carry traits related by DEPENDS_ON. Right-click the graph's board to create a new asset, or a new thing for assets to depend on.

Dependency graph

Every asset is a node, and so is everything an asset depends on or may depend on: other assets, aggregates and plain entities. An arrow points from an asset to what it depends on, which is drawn above it. Below an asset is its inside: its parts, with a dashed arrow from a part to each part it depends on, and the entities mappings derived from them. Select a node or an edge to act on it; right-click the board to create a new one.
