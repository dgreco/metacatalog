An asset type is an aggregate root type carrying the Asset trait. Its combined schema drives the whole tree below. Saving applies the whole document in one step: values are updated, parts added below are created, and parts removed from it are deleted with whatever was derived from them. Statuses are shown read-only — a run sets them, not this form. In an existing asset a part is referred to by its id, so dependsOn lists ids; which other assets this one depends on is easier to change from the catalog.
